# ATISセミナー型スライド（atis-deck）

近藤 活が 2026-10-05 ATIS AIセミナー（四日市）用に確立したデザインを、誰が作っても同じ水準で再現する skill。
**正本の手順書は同じフォルダの `AI BUDDY近藤.md`**（近藤作成・2026-09-28・Slack #general 共有版と同一）。本ファイルは Central AX ワークスペースでの起動方法と環境差分だけを書く。**手順・数値・ルールは `AI BUDDY近藤.md` を必ず全文読んでから従う**。食い違ったら `AI BUDDY近藤.md` を優先する。

## フォルダ構成（近藤の zip をそのまま展開したもの）

| パス | 用途 |
|---|---|
| `AI BUDDY近藤.md` | 手順書の正本。最初に全文読む |
| `見本/` | Canva版から切り出した完成ページ（公開版は15枚。価格ページは除外）。**見た目の正解**。作る前に全部 Read で見る。見本に写っている花は使わない |
| `template.html` | 基本CSS＋8種のひな形（章扉／大きい数字／比較／ビフォーアフター／縦ステップ／画面つき／ドーナツ／横棒）。コピーして書き換える。値は変えない |
| `プロンプト/` | 近藤が実際に使った画像生成プロンプト3本（業務イラストの型／たとえ図の街／横長の伴走4人） |
| `assets/corner_bottom.png` | 右下の実と葉。表が全幅のページには置かない |
| `html2pptx.py` | HTML→Canvaで文字を直せるネイティブPPTX |
| `audit_slides.py` | 「AIっぽさ」を数える自動チェック（箱／18px未満／最大文字／横3-4分割／はみ出し／実画像数） |

## 進め方（`AI BUDDY近藤.md`「Claude Code へ」の要約）

1. `見本/` 16枚を全部見る → 2. `template.html` をコピーして組む（CSSを書かない・値を変えない・部品を増やさない） → 3. **2〜3枚だけ作って画像にして依頼者に見せ、赤が入ってから残りを作る** → 4. `audit_slides.py` と「11. 仕上げチェックリスト」を通す → 5. `html2pptx.py` でPPTX化し、レンダリングを自分の目で見てから報告する。

最優先ルール（「2. 脱AIっぽさ」）: 囲みの箱は1枚1個まで／実画像をデッキで10枚以上／18px未満禁止・60px以上の主張を1ページ1つ／余白は塗り面と罫線で枠取り。

## Central AX 環境での差分

- **作業場所**: デッキのHTMLは `スライド資料/_build/atis/<案件名>/deck.html` のように案件ごとのフォルダに置き、`template.html`・`assets/`・見本画像はその相対パスで参照するか、skill フォルダからコピーする。skill フォルダ内に成果物を作らない
- **Python**: この環境は `python`（3.13）。手順書の `python3` は `python` に読み替える。依存（playwright・python-pptx・lxml・pillow・chromium）は導入済み。初回に Chromium 起動と Google Fonts の読込で数十秒〜数分かかることがあるので、`timeout` を長めに取る
- **html2pptx.py は Windows 向けに1か所だけ直してある**: 近藤の原本は macOS 前提で、`file://` URL の pathname 先頭 `/` をそのまま `pathlib.Path` に渡すため Windows では画像パスが `\C:\...` に化けて「⚠ 画像なし」になる。`local_path()` を足して先頭 `/` を落とす（2026-09-28・Central AX 環境で確認）。それ以外は原本どおり
- **html2pptx.py のパス解決**: HTML と `-o` の出力先は「html2pptx.py があるフォルダ基準」で解決される。skill 外の HTML を変換するときは**絶対パス**で渡す（`python ".claude/skills/atis-deck/html2pptx.py" "C:\...\deck.html" -o "C:\...\out\deck.pptx"`）。SVG の撮影用PNGは skill 内 `out/board/_svg/` に一時生成される（`.gitignore` 済み）
- **画像生成**: AGENTS.md の分担どおり、画像生成は Codex へ agmsg で依頼するのが一次経路（プロンプトは `プロンプト/` の型を渡し、SUBJECT だけ差し替える。JSON で用途・構図・スタイル・避けたい表現を先に整理する）。松浦の好み（AI感を抑える・赤は1か所・4段階の青）は手順書「7.」と一致。手描きSVGで代用しない
- **Canva 取り込み**: PPTX を Canva に入れる工程は `canva-editable` skill の「pptx往復禁止・100p上限」の制約と、手順書「10.」の Canva の癖（Claude経由の文字置換で箱が3.4倍に膨らむ→文言修正はCanva上で人が行う）を両方守る
- **ブランド**: この型は ATIS 佐藤氏デザイン由来の**紺 `#003383`**。ATIS 案件・近藤担当の登壇・「この型で」と明示された依頼で使う。Central AX 名義の資料に使ってもよい（2026-10-13 松浦が旧「Central AX名義には使わない」ルールを撤回）
