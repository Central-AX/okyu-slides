# okyu-slides

デザインが2種類あります。作る前にどちらを使うか決め、そのフォルダの手順書を**全文読んでから**作ります。

| デザイン | フォルダ | 見た目 | 最初に読むもの |
|---|---|---|---|
| A | `style-a/` | 紺の枠が全周を囲む・大きい数字で主張する | `style-a/手順.md` → `style-a/AI BUDDY近藤.md`（手順書の正本） |
| B | `style-b/` | 紙面グレー・紺の枠を四隅で崩す・左上に薄い特大番号・LINE Seed JP | `style-b/手順.md` → `style-b/デザイン仕様.md` |

## 選び方

- 依頼者が指定していればそれに従う（「紺枠」「A」→ A、「特大番号」「グレー」「B」→ B）
- 指定がなければ、A と B の見本を1枚ずつ見せて選んでもらう（`style-a/見本/`・`style-b/見本/`）
- 1つのデッキで A と B を混ぜない

## 共通の進め方

1. 選んだフォルダの `見本/` を全部見る（見た目の正解）
2. `template.html` をデッキの作業フォルダにコピーし、型の `<section>` を複製して中身だけ書き換える。CSS を書き足さない・値を変えない
3. まず2〜3枚だけ作って画像にして依頼者に見せ、OK が出てから残りを作る
4. `audit_slides.py` を通す → `html2pptx.py` で PPTX にする → PPTX を画像にして全枚自分の目で見てから報告する
5. スクリプトは「スクリプトのあるフォルダ基準」でパスを解決するので、skill 外の HTML は絶対パスで渡す（例: `python "<このskill>/style-b/html2pptx.py" "C:\...\deck.html" -o "C:\...\deck.pptx"`）

## 使うときの読み替え

- 各 `手順.md` の「Central AX 環境での差分」節は作成元（Central AX）の社内環境向け。作業フォルダの場所・画像生成の依頼先（Codex・agmsg）は、この PC の環境に読み替える。画像は依頼者に用意してもらうか、Claude が作る
- 表紙・章扉の写真とロゴは作成元の見本のもの。依頼者から自社の写真・ロゴをもらって差し替える（B の表紙・章扉・ロゴは仮画像が入っている）（B は `style-b/手順.md`「写真の差し替え」に手順あり）
- 見本の文言・数字・価格は見た目の参考。内容として流用しない
- 必要なもの: Python 3、`pip install playwright python-pptx lxml pillow`、`python -m playwright install chromium`。B を PowerPoint で同じ見た目にするには LINE Seed JP（OTF版・無料）をPCに入れる
