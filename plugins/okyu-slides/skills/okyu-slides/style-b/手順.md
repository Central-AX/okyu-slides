# 伴走支援セミナー型スライド（atis-bansou-deck）

ATIS 側デザイナーが仕上げた103枚の投影デッキ（2026-10 ATIS「AI企業型伴走支援セミナー」）の見た目を、誰が作っても同じ水準で再現する skill。
骨格は `atis-deck`（近藤のCanva版）と同じだが、**デザインは別物**（紙面 `#F2F2F2`・紺の枠は四隅のストライプで崩す・左上に薄い特大番号・全文 LINE Seed JP Bold）。
**数値と型の正本は同じフォルダの `デザイン仕様.md`**。作る前に全文読む。食い違ったら `デザイン仕様.md` と `template.html` を優先する。

## フォルダ構成

| パス | 用途 |
|---|---|
| `デザイン仕様.md` | 色・フォント・ページ骨格の座標・型一覧と見本の対応・脱AIっぽさルール。最初に全文読む |
| `見本/` | 元PDFから切り出した完成ページ（公開版は25枚）（1920×1080）。**見た目の正解**。作る前に全部 Read で見る |
| `template.html` | 基本CSS＋17種のひな形（表紙／INDEX／章扉／節扉・紙面版／問いかけ／大きい数字2カード／数字＋実画面／比較VS／4カード時間削減／縦ステップ／3つの数字／やったこと→起きたこと／プラン3列／締め／節扉・紺ベタ版／ドーナツ2つ／主張文＋補足箱）。**CSSはここに1回だけ書いてある。ページは `<section>` をコピーして文言・数字・画像だけ書き換える** |
| `assets/fonts/` | LINE Seed JP（Rg/Bd/Eb の woff2・OFL）。template は相対パスで読む |
| `assets/cover_sample.jpg`・`assets/chapter_sample.jpg` | 表紙用・章扉用の仮画像。自社の写真から `render.py --bake` で作って差し替える |
| `assets/logo_white.png` | 章扉・INDEX・節扉（紺ベタ版）右下の白ロゴの仮置き。自社の白ロゴに差し替える |
| `assets/placeholder_screen.png` | 「数字＋実画面」の実画面の仮置き。実際のスクリーンショットに差し替える（角丸は画像側に焼き込む） |
| `render.py` | HTML の全ページを `out/render/pNN.png` に書き出す。`--overlay 校正用/…png --page N` で重ね画像、`--bake 写真 --name 名前` で表紙・章扉の背景を作る |
| `html2pptx.py` | HTML→文字を直せるネイティブPPTX（atis-deck と同じもの。フォント名と既定の出力名だけ変えてある） |
| `audit_slides.py` | 「AIっぽさ」を数える自動チェック（この型の値に合わせてある） |

## 進め方

1. `デザイン仕様.md` と `見本/` 全部見る
2. `template.html` をデッキの作業フォルダにコピーし、`assets/` も一緒にコピーする（相対パスで読むため）。ページは型の `<section>` を複製して中身だけ書き換える。**CSSを書き足さない・値を変えない・部品を増やさない**。どうしても型に無い図が要るときは、白カード＋既存の文字クラスで組み、足した理由を報告に書く
3. **2〜3枚だけ作って `render.py` で画像にして依頼者に見せ、赤が入ってから残りを作る**
4. `python audit_slides.py deck.html` を通して指摘ゼロにする。数字の位置を型から動かしたページは `render.py --overlay` で見本と重ねて確かめる
5. `python html2pptx.py deck.html -o out/deck.pptx` で PPTX 化し、**PPTX をレンダリングした画像を自分の目で全枚見てから報告する**（「⚠ 画像なし」が出たら画像パスを直す）

### 脱AIっぽさルール（詳細は `デザイン仕様.md` 5章）

- 1ページ1主張（60px 以上の「文」は1つ。数字は数えない）
- 赤は強調のためだけに使い、1ページ2か所まで（同じ役割の並び＝例：3つの数字、起きたことの3行は1か所と数える）
- 囲みは白カードのみ。枠線だけの箱・影つきの箱を作らない
- 横3〜4分割グリッドを連発しない（連続する2枚で使わない）
- 実画面・イラストをデッキで10枚以上入れる
- 12px は英字キャプション、17px は出典・注記だけ。他は 20px 以上
- 枠・ストライプ・特大番号の値を変えない。部品を増やさない

## Central AX 環境での差分

- **作業場所**: デッキは `スライド資料/_build/atis_bansou/<案件名>/deck.html` のように案件ごとのフォルダに置き、`assets/` をその横にコピーする。skill フォルダ内に成果物を作らない（`out/` は `.gitignore` 済みの作業用）
- **Python**: この環境は `python`（3.13）。playwright・python-pptx・lxml・pillow は導入済み。LibreOffice は無いので、PPTX の目視は PowerPoint の COM で書き出す（`$pres.Slides(i).Export(path,"PNG",1280,720)`）
- **スクリプトのパス解決**: `render.py`・`html2pptx.py` は「スクリプトのあるフォルダ基準」で相対パスを解決する。skill 外の HTML は**絶対パス**で渡す（`python ".claude/skills/atis-bansou-deck/html2pptx.py" "C:\...\deck.html" -o "C:\...\out\deck.pptx"`）
- **フォント**: HTML は `assets/fonts/` の woff2 で表示される。PPTX には書体名 `LINE Seed JP_OTF` で入るので、**PC に LINE Seed JP（OTF版）が入っていないと PowerPoint では代替フォントで表示される**（2026-09-29 時点でこの PC は未インストール）。Canva に入れる場合は Canva 側の書体を LINE Seed JP に揃える
- **ドーナツなど SVG と PPTX**: html2pptx.py は SVG を要素ごとに透過PNGで撮って画像にする。撮影中は対象 SVG 以外を隠し紙面も透明にするので、輪の下の特大番号や紙面は写り込まない（2026-09-29 Central AX で修正。atis-deck 版には無い）。`class="figtxt"` は互換のため残してあるが必須ではない。SVG の中の文字は画像になるので、数字・ラベルは HTML で上に重ねる
- **角丸カード**: html2pptx.py は `border-radius` が 1px を超える塗りの箱を PowerPoint の角丸四角形にする（2026-09-30 Central AX で修正。atis-deck 版は四角のまま出る）
- **PPTX に移らないもの**: letter-spacing（字間）・CSS の角丸付き border・透明度・ブレンド。template はこれを避けて組んである（カードの縁は「灰の角丸＋内側の白」、章扉の紺×写真は焼き込み画像、薄い英字は不透明色）
- **写真の差し替え**: `python render.py --bake 新しい写真.jpg --name 案件名 [--place x,y,幅]` → `assets/cover_案件名.jpg` と `assets/chapter_案件名.jpg` ができるので、template の `src` を差し替える。章扉の色は「紺ベタの上に写真をスクリーン28%」（ATIS 版の実測）
- **Canva 取り込み**: PPTX を Canva に入れる工程は `canva-editable` skill の制約（pptx往復禁止・100p上限）に従う
- **画像生成**: AGENTS.md の分担どおり Codex へ agmsg で依頼する。用途・構図・スタイル・避けたい表現を JSON に整理してから渡す
- **ブランド**: この型は ATIS 由来の紺 `#003383`×赤 `#E43C59`。どの会社名義の資料に使ってもよい。社名表記は「Central AX」（全大文字にしない）
