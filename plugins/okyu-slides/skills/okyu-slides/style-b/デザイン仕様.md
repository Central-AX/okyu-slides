# 伴走支援セミナー型 デザイン仕様

> 公開版の注記: 見本のうち表紙・INDEX・章扉（写真×紺）・実画面・自己紹介・提供するもの・プラン・特典は除外しています。`校正用/` も含みません（`render.py --overlay` は使えません）。表紙・章扉・ロゴは仮画像なので差し替えて使ってください。

元資料 `AI企業型伴走支援セミナー_スライドデザイン.pdf`（103枚・1280×720）を PyMuPDF で実測した値（2026-09-29）。単位は px。
bbox は PDF の文字枠（上端〜下端＝ascender〜descender、行ボックス高さ ≈ 文字サイズ×1.67）。CSS の top は **ベースライン − 0.84×文字サイズ**（LINE Seed JP・line-height:1）で置いている。
`template.html` の CSS はこの表の値そのもの。ページを作るときは値を変えない。

## 5. 脱AIっぽさルール

| ルール | 中身 | audit_slides.py |
|---|---|---|
| 1ページ1主張 | 60px 以上の「文」は1つ（数字・単位は数えない）。この型の主張は結論行 50px | 60px 以上でかな漢字3文字以上の文字が2つ以上ならNG |
| 赤は2か所まで | 強調のためだけに使う。同じ役割の並び（3つの数字、起きたことの3行、ピルの対）は1か所と数える | 検査しない（目で見る） |
| 囲みは白カードだけ | 枠線だけの箱・影つきの箱を作らない | 3辺以上の border か box-shadow を持つ文字入りの箱が1つでもあればNG |
| 分割を連発しない | 横3〜4分割グリッドを連続する2枚で使わない | 連続したらNG（1枚だけなら「（横3/4分割）」と表示するだけ） |
| 実画面・イラスト | デッキで10枚以上。ロゴ・表紙/章扉の背景は数えない | 合計枚数を表示 |
| 小さい文字 | 12px は英字キャプション（`.cap`）、17px は出典・注記（`.src`）だけ。他は 20px 以上 | 18px 未満は `.cap` `.src` 以外NG |
| 部品を変えない | 枠・ストライプ・特大番号の値を変えない。部品を増やさない | 特大番号（`.bignum`）と薄い英単語（`.ghost`）は集計から外す。見出し 40px 未満しか無いページはNG（表紙は除く） |
| はみ出し | 文字は紙面 (20,20)-(1260,700) の内側 | 外に出たらNG（特大番号・薄い英単語は除く） |
